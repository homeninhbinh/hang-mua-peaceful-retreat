# Hang Mua Peaceful Retreat – Landing Page

Website landing page cho homestay tại Ninh Bình.

## Chạy local

Mở trực tiếp file `index.html` trong trình duyệt, hoặc dùng live server:

```bash
npx serve .
```

## Tùy chỉnh nhanh

| Nội dung | File |
|----------|------|
| Số Zalo | Tìm `0336724017` trong `index.html` |
| Ảnh thật | Thay URL Unsplash trong `index.html` bằng ảnh homestay |
| Địa chỉ / Facebook | Phần Footer và Map trong `index.html` |
| Màu sắc | Biến CSS trong `css/style.css` (`:root`) |
| Giá phòng | Section `#phong` trong `index.html` |
